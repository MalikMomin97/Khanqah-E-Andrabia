# Khanqah-e-Andrabia • Astaan Hazrat Mir Syed Kamal-ud-Din Andrabi (R.A.)

> **Sonwar Bagh, Srinagar, Jammu & Kashmir (190004)**  
> Indo-Islamic Archival Monograph Record #10504 • Wisal Mubarak: 16 Jumada al-Awwal 1081 AH

An institutional web sanctuary and archival digital monograph dedicated to **Khanqah-e-Andrabia** and **Hazrat Mir Syed Kamal-ud-Din Andrabi (R.A.)**. Crafted in an imperial dark gold and obsidian Islamic aesthetic inspired by classical Kashmiri vernacular wooden architecture and the *Shaha* Islamic design system.

---

## 🌟 Features & Highlights

- **Shaha Architectural Hero Carousel**: Fullscreen evocative slideshow highlighting the sanctuary, weekly Khatmat, the historic Pagoda spire (*Burj*), and certified archival manuscripts.
- **Authentic Archival Chronicle & Shajarah**: Verified 8-generation lineage of Sadat-e-Andrabiya from Sayyid Ahmad Andrabi (781 AH / 1379 CE, companion of Amir-e-Kabir Mir Syed Ali Hamadani) to Hazrat Mir Syed Kamal-ud-Din Andrabi (1081 AH / 1670 CE).
- **Daily Prayer Times & Sacred Liturgies**: Five daily congregation schedules, weekly Thursday *Khatam-e-Sharief*, Friday congregational majalis, and daily *Aurad-e-Fathiya* recitations.
- **Hijri Calendar & Annual Urs Commemorations**: Dedicated calendar tracking of the central annual Urs (16th Jumada al-Awwal) and major Islamic observances.
- **Interactive Sanctuary Navigation & Map**: Precise geographic coordinates (34.0736° N, 74.8427° E) with integrated Google Maps route planning.
- **Documentary & Video Archive**: Embedded documentary video documentation of the Astaan with responsive playback.
- **Bilingual & Responsive**: Fast, responsive layout tuned for all viewports from mobile (320px) to ultra-wide 4K displays.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/MalikMomin97/Khanqah-E-Andrabia.git

# Enter project directory
cd Khanqah-E-Andrabia

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
